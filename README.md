# 📚 StudyShelf – Digital Library

StudyShelf is a responsive digital library website developed using HTML, CSS, and JavaScript. It allows students to explore educational books, tutorials, courses, and study materials from trusted online learning platforms.

## ✨ Features

- 📖 **Resource Collection:** Browse 15 educational resources.
- 🔍 **Search Functionality:** Search resources by title.
- 🗂️ **Subject Filters:** Filter resources by Computer Science, Mathematics, Science, Engineering, Business, and General.
- 🔗 **Authorized Resources:** Access original learning materials through external educational platforms.
- 📱 **Responsive Design:** Works across desktop, tablet, and mobile devices.
- 💡 **Interactive Interface:** Dynamic resource cards and helpful empty-state messages.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive layout
- JavaScript – Search, filtering, and dynamic resource display

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Browse the library, search for resources, and explore different subjects.
